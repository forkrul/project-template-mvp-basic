# forkrul-mvp-template

Minimal, agent-ready Python/uv service skeleton for the forkrul estate: dual CI
(Woodpecker + GitHub Actions) driven through one Makefile, local pipeline parity
in Docker, an opt-in menu of shared `forkrul-*` packages, and this documentation
site — built with `sphinx-build -W`, so a single warning fails the build.
